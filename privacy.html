Акаунт

Політика · робоча чернетка

Ваші дані — ваша довіра.

Цей текст описує поточний MVP і потребує юридичної перевірки до використання з реальними клієнтами.

Які дані обробляються

Для входу Supabase Auth обробляє email і пароль та надсилає підтвердження/відновлення. Після реєстрації SoundCollab зберігає ім’я, ролі client/performer, згоду з цією політикою й профільні дані, які ви додаєте.

Замовлення та взаємодія

Опис проєкту, бюджет, дедлайн, повідомлення, зустрічі, передані матеріали й журнал змін доступні учасникам відповідного замовлення через політики доступу Supabase. Адміністратори бачать замовлення, його чат, журнал і файли лише поки відкритий спір; після рішення цей доступ закривається. Профілі виконавців можуть бути видимі зареєстрованим користувачам, приватні профілі клієнтів — лише власнику й учасникам спільного замовлення. Службовий прапорець адміністратора та час згоди не надаються через API профілю. Файли зберігаються у приватному bucket; посилання для перегляду тимчасові.

Мета, зберігання та права

Дані використовуються для роботи акаунта, замовлення, безпеки та підтримки. У цьому MVP ще немає автоматизованого експорту/видалення профілю, аналітики чи окремих повідомлень про замовлення. Передайте запит на доступ, виправлення чи видалення через контактну форму; оператор має обробити його вручну з урахуванням законних строків зберігання.

Сторонні сервіси та обмеження

Сайт розміщений на GitHub Pages, Auth/дані/Storage/Realtime на Supabase, бібліотека Supabase JS завантажується з esm.sh. Посилання на відеозустріч можуть вести на Jitsi, Zoom, Google Meet або Teams; їхні правила конфіденційності діють окремо. Не надсилайте паролі, платіжні реквізити чи дані, не потрібні для замовлення.

Оновлення

Публічна версія зараз позначена як робоча чернетка, версія для згоди в базі — 2026-10-15. Власник сервісу має замінити ці контакти, строки зберігання, юридичну підставу та механізм видалення на узгоджену політику перед публічним запуском.
